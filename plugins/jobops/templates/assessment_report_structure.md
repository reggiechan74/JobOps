# Assessment Report Structure Template

**MANDATORY FORMAT** - All assessment reports must follow this structure for consistency and traceability.

## Purpose

This template defines the standard format for candidate assessment reports. It ensures consistent documentation, proper evidence mapping, and clear audit trails across all assessments.

## Commands That Reference This Template

- `/assessjob` - Uses this structure for assessment reporting
- `/assesscandidate` - Uses this structure for assessment reporting
